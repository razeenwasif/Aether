Design · canvas v11

What it looks like

The 12 boards on the design canvas (1440 × 900 unless noted). One sample project, Lumen, a small lantern game, runs through all six workspaces so you can follow a single asset from one mode to the next.

Open the original design canvas ↗
Design · ⌘1 Design workspace Desktop and mobile breakpoints side by side. The selected button shows its auto-layout parent, and the inspector leads with tokens and the synced code. The 32 pt rail on the left holds the workspaces, Run, Search and the panel toggles, all set as vertical text.
Model · ⌘2 Model workspace No transform gizmo: the face is the handle, with a contextual bar of Extrude, Inset, Bevel and Loop cut. Materials are a short layer stack.
Game · ⌘3 Game workspace (editing) A room fed live by Canvas’s layers, with an ECS outliner and the lantern’s behaviour graph in a drawer below.
Game · playing Play in the viewport Run turns to Stop. Overlays and drawers step aside, and the HUD shows time, step-frame and frame timing. No separate game window.
Canvas · ⌘4 Canvas workspace The navigator is hidden by default while painting. Vector booleans stay editable, and each layer is a Game parallax plane.
Diffuse · ⌘5 Diffuse workspace The flow’s sources are a Model depth pass and the Canvas painting. Its output is the live key art in Design and Video.
Video · ⌘6 Video workspace A real programme monitor at last, with a magnetic storyline whose clips come live from every other workspace.
Omnibar · ⌘K Omnibar Tools, actions, assets and Go-to in one list, with the selection’s likeliest commands first. Filters as you type.
Asset pipeline · 1440 × 1040 One project graph, six views Every workspace reads and writes one graph through transactions. Regenerate the key art and the hero and shot 3 update in place.
Velvet Obsidian · 1440 × 2000 Design system Colour, type, elevation, inspector rules, components, motion and keys.
App icon App icon Six facets, one per workspace, on an obsidian squircle, shown at small sizes, in the Dock, and as a template glyph (design/photon-icon.svg).
Chrome

Greyscale throughout, so the work is the only colour on screen. Run is the one bright control, in the same slot with the same shortcut in every workspace.

Signals

Ice for selection, lavender for generative work, mint for live links and playing. Each always comes with a second cue: a label, an icon or a shape.

Layout

A 32 pt rail; a full-bleed viewport; navigator (⌘0) and inspector (⌘\) floating as glass; a contextual action bar beside the selection; a tool dock that re-centres in the free space.

Decisions · RESEARCH_PLAN.md §9

Decided

Five questions, settled on 27 Oct. Every card says what was chosen and what it changes.

Q1 · decided 27 Oct

Rust document cores, or a Swift rewrite?

Proton’s raster engine, game simulation, flow and EDL code is Rust and already tested for byte-identical output.

  • aRewrite in Swift: one language, but re-prove determinism.
  • bLink the Rust cores via UniFFI: still native, formats stay shared with Proton.

(b). Link Proton’s Rust cores through UniFFI for formats, ops, the simulation and the raster engine. UI, rendering and media stay Swift and Metal.

Q2 · decided 27 Oct

Which macOS is the floor?

The floor decides whether the glass is Liquid Glass or hand-built materials, and whether Metal 4 paths are available.

  • amacOS 26 and later.
  • bmacOS 15, with fallbacks.

(a) macOS 26 and later. Panels use glassEffect, and Metal 4 is always available.

Q3 · decided 27 Oct

Where does Diffuse run by default?

Local Core ML is private and offline. forge’s RTX 4090 through Nexus is faster and runs every model Nexus has.

  • aLocal by default, Nexus per flow.
  • bNexus by default, local when forge is away.

(a). Core ML on the Neural Engine and GPU by default; a flow can switch to Nexus on forge, and the Run button names the backend.

Q4 · decided 27 Oct

Which plugin runtime?

Plugins add tools, nodes and inspector sections through a capability-scoped host API.

  • aWasmtime: mature, Rust.
  • bWasmKit: Swift-native, younger.

(a) Wasmtime, since the Rust cores are linked anyway (Q1).

Q5 · decided 27 Oct

Keep the traffic lights stacked?

Stacking them down the 32 pt rail means re-laying out AppKit’s titlebar buttons, or drawing our own and losing the system hover glyphs.

  • aStacked, as designed, if the spike is robust.
  • bHorizontal in a corner above the rail.

(a) Stacked, as designed. M0 proves it; the corner fallback is used only if it breaks on resize or full screen.
